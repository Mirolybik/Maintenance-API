# Maintenance API (Кейс 4: Промышленный стек)

Комплексный сервис учёта технического обслуживания парка ветрогенераторов и подстанций. Сервис полностью подготовлен к промышленной эксплуатации: закрыт аутентификацией с ролевой моделью (RBAC), упакован в контейнеры под управлением Nginx reverse proxy и подключен к дашбордам мониторинга Grafana.

## 🏛️ Схема целевой архитектуры
```text
  [ Клиент / Браузер ]
          │ (HTTP :80)
          ▼
    [ Nginx Reverse Proxy ]
          │ (proxy_pass :3000)
          ▼
   [ Node.js Express API ] ─── (/metrics) ───► [ Grafana (:3001) ]
          │                                           ▲
          │ (SQL / Pool)                              │
          ▼                                           │ (Datasource)
  [ PostgreSQL Database ] ────────────────────────────┘

🛠️ Эксплуатационный регламент (Runbook)Проверка здоровья процесса: GET /api/health/live (проверка процесса Node.js).Проверка готовности сервиса: GET /api/health/ready (проверка соединения с PostgreSQL).Действия при падении БД: При сбое базы эндпоинт /api/health/ready возвращает статус 503 Service Unavailable. Сервис не падает в unhandled rejection, а ожидает восстановления пула соединений.Откат миграций БД:Bashnpm run db:migrate:undo
