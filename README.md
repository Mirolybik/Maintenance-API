# Maintenance API (Кейс 2)

REST API для учета заявок на обслуживание оборудования. Разработан на Express со строгой слоистой архитектурой.

## Особенности (исправления по ревью)
- **Строгая валидация**: Использован `z.object().strict()`. Любые неизвестные поля отклоняются с кодом 422.
- **Безопасный JSON**: Middleware `errorHandler` явно перехватывает `SyntaxError` от `express.json()`, не допуская утечки сырого HTML/текста клиенту.
- **Чистый код**: Никаких `var`, `==` или закомментированных `console.log`. Используется современный логгер `pino`.
- **Настоящие тесты**: `jest` + `supertest` дергают инстанс `app.js` и проверяют реальные HTTP ответы (в т.ч. 400 и 422).
- **Git Flow**: Проект разбит на логические ветки (feature branches).

## Установка и запуск
```bash
npm install
cp .env.example .env
npm run dev
```

## Docker
```bash
docker-compose up --build
```

## Безопасность
- CORS разрешен только для URL из `CORS_ORIGINS`.
- Ограничение запросов (Rate Limit) и ограничение тела `100kb`.
- Helmet проставляет защитные заголовки.
